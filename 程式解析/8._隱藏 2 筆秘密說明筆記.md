# 8. 隱藏 2 筆秘密說明筆記

---

## 這個功能是做什麼的？

InvASNet 預設一次只藏一段秘密音訊（Secret）進載體音訊（Cover）。
**雙秘密模式**可以同時把**兩段**秘密音訊藏進同一段載體，讓接收方能同時提取兩段內容。

```
單秘密模式：  [Cover]  +  [Secret 1]             → [Stego]
雙秘密模式：  [Cover]  +  [Secret 1]  +  [Secret 2]  → [Stego]
```

---

## 網路結構的差異

在可逆神經網路（INN）的架構下，輸入通道數會不一樣：（註：通道數會因為做了幾次小波轉換而改變，下面以 1 次小波轉換為例）

| 模式 | 網路輸入通道數 | 說明 |
|------|--------------|------|
| 單秘密（`num_secrets=1`） | 4C | Cover(2C) + Secret1(2C) |
| 雙秘密（`num_secrets=2`） | 6C | Cover(2C) + Secret1(2C) + Secret2(2C) |

> **注意：** 這兩種模式的網路結構不同，**不能互用模型權重**。換模式就必須從頭重新訓練。

---

## 如何啟用雙秘密模式？

### 步驟一：修改 `config.py`

找到這一行，把 `1` 改成 `2`：

```python
# 原本
num_secrets = 1

# 改成
num_secrets = 2
```

### 步驟二：準備資料集

需要新增第二筆秘密音訊的資料夾。資料夾結構如下：

```
data/
├── train/
│   ├── host/        ← 載體音訊（音樂）
│   ├── secret/      ← 第一段秘密音訊
│   └── secret2/     ← 第二段秘密音訊（雙秘密模式新增）
└── val/
    ├── host/
    ├── secret/
    └── secret2/     ← 驗證用的第二段秘密音訊
```

`config.py` 裡的路徑設定已預先寫好，不需要額外修改：

```python
TRAIN_SECRET2_PATH = os.path.join(INVASN_DATA_ROOT, "train", "secret2")
VAL_SECRET2_PATH   = os.path.join(INVASN_DATA_ROOT, "val",   "secret2")
```

只要確保 `secret2` 資料夾裡有 `.wav` 檔就會自動啟用。

### 步驟三：重置訓練設定並重新訓練

因為網路結構改變了，必須從頭訓練：

```python
tain_next     = False   # 不讀取舊模型
trained_epoch = 0       # 從第 0 輪開始
```

然後執行 `train.py` 即可。

---

## 訓練時發生了什麼？

程式讀到 `num_secrets = 2` 後，會自動把兩段秘密一起丟進網路：

```python
# train.py 的核心邏輯
x = torch.cat([cover_d, secret1_d, secret2_d], dim=1)  # 合併成 6C 輸入
y = net(x, rev=False)                                   # 正向：隱藏
```

注意到，程式這裡把 Cover 和 Secret1、secret2 合併成一份東西，這份東西會在 invblock.py 中依據 hinet.py 提供的通道數切分成 Cover 和 Secret

提取時，模型輸出後半部分會再切成兩半，分別還原：

```python
half = secret_hat_all.shape[1] // 2
secret1_hat = secret_hat_all[:, :half, :]   # 第一段秘密
secret2_hat = secret_hat_all[:, half:, :]   # 第二段秘密
```

換句話說，藏入兩筆秘密的原理其實只是把兩筆秘密的張量合併成一份 2 倍大的秘密，

---

## 如何用 app.py 測試雙秘密？

啟動 `app.py` 後，介面上會自動出現第二個秘密音訊的上傳框（當 `num_secrets=2` 時）。

**藏入流程：**
1. 上傳 Cover 音樂
2. 上傳 Secret 1 音訊
3. 上傳 Secret 2 音訊（雙秘密模式才會顯示）
4. 按下「開始隱寫」

**提取流程：**
1. 上傳 Stego 音訊
2. 按下「開始提取」
3. 會同時輸出兩段還原的秘密音訊

---

## 注意事項

- 藏兩段秘密比藏一段**更容易產生高頻雜音**，因為需要嵌入的資訊量加倍
- `secret_target_rms` 的設定對雙秘密模式尤其重要，兩段秘密都會被正規化到同一個響度
- 如果 `secret2` 資料夾是空的，程式會報錯；確保訓練和驗證資料夾都有檔案
- 三組資料（host、secret、secret2）的數量不需要相同，程式會取最少的那個作為資料集大小

---

## 小結

| 項目 | 說明 |
|------|------|
| 啟用方式 | `config.py` 中設定 `num_secrets = 2` |
| 需要的額外資料 | `data/train/secret2/` 和 `data/val/secret2/` 各放一批 `.wav` |
| 是否需要重新訓練 | **需要**，舊模型無法直接使用 |
| 提取出的秘密數量 | 2 段 |
| 代價 | 載體音訊的隱蔽性略降（嵌入資訊量加倍） |
